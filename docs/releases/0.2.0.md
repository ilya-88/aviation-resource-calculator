# Авиаресурс 0.2.0 — Android-прототип

Дата: 21 ноября 2026 года.

## Результат

- Собран Android APK с пакетом `ru.smolnikov.aviaresource`.
- Минимальная версия Android: 8.0 (API 26).
- Целевая версия Android: API 36.
- Веб-интерфейс встроен внутрь APK и работает без интернета.
- Добавлен мост к системному календарю и уведомлениям Android.
- Сохранение смен изменяет счётчики самолёта, двигателей и ресурсов.

- `node --test tests/calculations.test.js`: 4/4 теста успешно.
