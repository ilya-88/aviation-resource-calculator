# Авиаресурс

Первый интерактивный прототип персонального приложения для учёта ресурсов самолёта, двигателей и агрегатов.

Рабочая версия: <https://ilya-88.github.io/aviation-resource-calculator/>

Android APK 0.2.1: <https://github.com/ilya-88/aviation-resource-calculator/releases/download/v0.2.1/aviation-resource-0.2.1-prototype.apk>

## Запуск

Самый простой вариант — открыть `index.html` в браузере.

Для полноценной установки как PWA и офлайн-кэша запустите любой локальный статический сервер в каталоге проекта, например:

```powershell
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Реализовано в прототипе

- выбор самолёта и карточка борта;
- блоки формуляров, двигателей и агрегатов;
- сводка остатков ресурсов с поиском и сортировкой;
- ввод лётной смены;
- расчёт земной наработки: округление до ближайших пяти минут и включение 20%;
- расчёт приведённых посадок;
- иерархия общих и самолётных уведомлений;
- создание самолётов и настраиваемых агрегатных блоков;
- сохранение смен с реальным начислением налёта, посадок, СНЭ и ППР;
- уменьшение остатков ресурсов и история последних смен;
- вызов системного календаря и Android-уведомлений из APK;
- локальное сохранение состояния;
- адаптивный интерфейс и PWA-манифест.

## Android APK

Android-проект находится в каталоге `android/`. Тестовый release APK собирается командой:

```powershell
cd android
.\gradlew.bat assembleRelease
```

Версия 0.2.1 подписана отладочным Android-сертификатом и предназначена только для прототипирования. Для магазинной публикации будет создан отдельный постоянный ключ выпуска.
